## English

Ferrum is a plugin framework project for **SCP: Secret Laboratory**. Our goal is to enable developers to write server plugins in **Rust**. The planned architecture connects Rust plugins to the game environment through a **C# bridge**, with integrations for **LabAPI** and **EXILED**.

**Status:** Alpha pre-release [v0.1.0](https://github.com/Ferrum-SCPSL/Ferrum/releases/tag/v0.1.0). The C# ↔ Rust bridge, localized runtime, updater and installers are implemented; user Rust-plugin loading is still planned. Only builds and static checks were performed. [Installation](Ferrum/docs/installation.md) · [Configuration](Ferrum/docs/localization.md) · [Verification](Ferrum/docs/verification.md).

Questions or ideas? [Open an issue](https://github.com/Ferrum-SCPSL/Ferrum/issues).

## 简体中文

Ferrum 是面向 **SCP: Secret Laboratory** 的插件框架项目。我们的目标是让开发者使用 **Rust** 编写服务器插件。规划中的架构将通过 **C# 桥接层**连接 Rust 插件与游戏环境，并集成 **LabAPI** 和 **EXILED**。

**项目状态：** Alpha 预发布版本 [v0.1.0](https://github.com/Ferrum-SCPSL/Ferrum/releases/tag/v0.1.0)。已实现 C# ↔ Rust 桥接、本地化运行时、更新程序及安装程序；用户 Rust 插件加载仍在规划中。仅进行了编译和静态检查。[安装](Ferrum/docs/installation.md) · [配置](Ferrum/docs/localization.md) · [验证状态](Ferrum/docs/verification.md)。
